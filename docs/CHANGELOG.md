# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/): мажор — ломающее изменение (например, `settings.json`, который старая версия не прочтёт), минор — новая функция, патч — только исправления. Номер версии — `<Version>` в `src/KbLight.csproj`.

## [Не выпущено]

### Изменено

- Первый запуск, без `settings.json`, больше не записывает в клавиатуру настройки автора («Рябь от нажатий»): трей читает подсветку, которая уже стоит в клавиатуре, и сохраняет её в `settings.json`.

### Добавлено

- Код возврата 3 у `--apply` и `--check`: `settings.json` ещё нет, клавиатура не тронута.

### Документация

- Проект переведён на OpenSpec: базовые спецификации поведения в `openspec/specs/` (8 capability), `openspec/config.yaml`, `docs/ARCHITECTURE.md`, `docs/PROTOCOL.md`, `docs/ADR.md`, `CLAUDE.md`, `AGENTS.md`. Поведение программы не менялось.
- Инструменты исследования протокола перенесены в проект: `tools/kbtool.py`, `tools/capture/`.

## [1.0.0] — 2026-10-04

### Добавлено

- Значок в трее; запись подсветки при входе в Windows, при подключении клавиатуры, после сна, после правки в окне и по команде «Применить сейчас».
- Окно «Подсветка клавиатуры»: 20 эффектов, яркость, скорость, цвет, разноцветный режим, направление, автозапуск, состояние, журнал.
- Автозапуск — задача планировщика `KbLight`; ключи `--tray`, `--apply`, `--check`, `--autostart on|off`.
- Журнал `%LOCALAPPDATA%\KbLight\kblight.log`.
