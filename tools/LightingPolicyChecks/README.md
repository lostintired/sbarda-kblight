# Проверки тихих часов

Нужны Windows и .NET 10 SDK. Сторонних пакетов нет. Проект компилирует исходные файлы приложения и заменяет только пути и журнал: настройки создаются в отдельном `%TEMP%\KbLightChecks\<случайное имя>`, пользовательский файл не меняется.

Обычная проверка не общается с клавиатурой:

```
dotnet run --project tools/LightingPolicyChecks -c Release
```

Проверяются точные границы ночного и дневного интервалов, выключенное/null расписание, неверное и равное время, все сочетания ручных выключателей, сохранение старых настроек, неизменяемость снимка, отправляемые яркости, статус и сохранность чужих байтов блока. Нарушение ожидания завершает процесс с кодом 1.

Проверка окна, без обращения к устройству:

```
dotnet run --project tools/LightingPolicyChecks -c Release -- --ui
dotnet run --project tools/LightingPolicyChecks -c Release -- --ui --dark --scale 1.5
```

`KBLIGHT_LANG=ru` или `en` выбирает язык; `--image <путь.png>` сохраняет изображение окна. `--scale 1.5` и `--scale 2` проверяют программное увеличение элементов и доступность кнопки через прокрутку; это не замена проверке физического переключения DPI монитора.

Вывод окна содержит фактический `DPI`, размер и рабочую область; `--image` также сохраняет `*-bottom.png` после прокрутки к кнопке «Закрыть». Для проверки физического масштаба 150/200% нужно подтвердить DPI 144/192; при DPI=96 проверка повышенного масштаба не засчитывается. Не пересобирать проект, пока работает его аппаратная проверка: исполняемая сборка заблокирована процессом.

Дополнительные проверки на живой клавиатуре:

```
dotnet run --project tools/LightingPolicyChecks -c Release -- --device
dotnet run --project tools/LightingPolicyChecks -c Release -- --tray
dotnet run --project tools/LightingPolicyChecks -c Release -- --wait
```

Перед ними закрыть sbarda.exe и установленный трей KbLight, сохранить исходный файл и блок. `--device` временно устанавливает яркости 65/35 и проверяет независимое выключение/возврат и чужие байты. `--tray` проверяет переходы на ближайших двух минутных границах, ночную правку до 80%, сохранение неизвестного Light box и ручное выключение после ночи; выполнение занимает до двух минут. `--wait` удерживает мьютекс устройства через ближайшую минутную границу и проверяет, что ожидающая запись пересчитывает время после его освобождения. Все аппаратные режимы восстанавливают исходный блок в `finally`, но после прерывания процесса нужно самостоятельно применить исходные настройки командой установленной программы `KbLight.exe --apply` и вернуть обычный трей. Не запускать kbtool параллельно с записью.

Вывод содержит число проверок, а аппаратные режимы — дополнительные блоки и строки журнала. Физическое отключение кабеля, реальный сон и изменение часового пояса этими командами не выполняются.
