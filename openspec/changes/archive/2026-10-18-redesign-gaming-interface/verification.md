# Проверка редизайна

Проверено 2026-10-18. Реализован настоящий интерфейс WinForms по согласованному HTML-макету. Установленная программа не заменялась, HID, очередь записи и политика расписания не изменялись. Проверочные процессы используют собственные данные в `%TEMP%\KbLightChecks\<случайное имя>`; аппаратные режимы не запускались.

- `dotnet build tools/LightingPolicyChecks -c Release -p:Version=1.4.0 -warnaserror`: 0 предупреждений, 0 ошибок. Параметр версии нужен для снимков проверочного проекта; версия приложения остаётся 1.4.0.
- `dotnet run --project tools/LightingPolicyChecks -c Release --no-build`: «Проверок пройдено: 97; ошибок: 0.»
- `openspec validate --all --strict`: 14 passed, 0 failed. Информационные замечания о длинных требованиях не являются ошибками.
- `git diff --check`: без ошибок.

## Проверки интерфейса

Для каждого языка `KBLIGHT_LANG=ru` / `en` выполнены команды `dotnet run --project tools/LightingPolicyChecks -c Release --no-build --` с аргументами из таблицы. Каждый запуск завершился строкой «Проверок пройдено: 269; ошибок: 0.»

| Вариант | Аргументы | Размер окна | Фактический DPI |
|---|---|---|---|
| Тёмная тема, обычный размер | `--ui --dark --image <путь>` | 1016 × 671 | 96 |
| Классическое оформление системных элементов, тёмное содержимое окна | `--ui --image <путь>` | 1016 × 671 | 96 |
| Программное увеличение 150% | `--ui --dark --scale 1.5 --image <путь>` | 1516 × 987 | 96 |
| Программное увеличение 200% | `--ui --dark --scale 2 --image <путь>` | 2016 × 1303 | 96 |
| Ограниченный размер | `--ui --dark --small --image <путь>` | 800 × 560 | 96 |

В итоговых запусках рабочая область была 2560 × 1392. В ранних запусках область 1920 × 1032 ограничивала увеличенное окно до 1920 × 1032; проверки доступности также прошли.

В эти 269 входят прежние 97 проверок политики и проверки реальной формы: загрузка/Reload без правок, выключатели, редактирование выключенного профиля с нулевой эффективной яркостью, поддержка всех 20 эффектов и пяти режимов Light box, независимость цветов, нормализация HEX, пять ошибочных вводов и возврат последнего цвета без события, чёрный/белый/серый/основные цвета, клавиатурное изменение ползунка/палитры/времени, доступное действие переключателя, отсутствующая модель и внешний статус, служебные события без записи света, ссылка обновления, скрытие второй колонки с освобождением места. Проверяются границы панели направления, достижимость обеих палитр/направления/версии прокруткой и закреплённые состояние/закрытие.

Три способа закрытия проверены в отдельных формах: кнопка, обработка Esc и сообщение SC_CLOSE заголовка. В каждом случае форма закрылась, сделанная перед этим правка передана подписчику и осталась в объекте профиля. Это не аппаратная проверка записи после закрытия; прежний `TrayApp.FormClosed → FlushEdits` не менялся.

- `%TEMP%\KbLight-redesign-20261018\` — выводы и снимки ru/en для классического режима, программных 150/200%, 800 × 560, варианты `*-bottom.png`.
- `%TEMP%\kblight-redesign-icons.png` — значки 16/20/24/32/40/48/64 на светлом и тёмном фоне; просмотрены. Повторная генерация `python tools/make_icon.py` дала тот же SHA256 ICO.

Просмотр снимков подтвердил компоновку и отсутствие обрезания параметров внутри панелей. При 800 × 560 начальный кадр намеренно показывает часть горизонтального содержимого: остальные поля достижимы прокруткой. Рамка заголовка в `DrawToBitmap` рисуется системным способом; это не снимок композитора рабочего стола. Рабочая форма отдельно запрашивает тёмный заголовок через DWM.

## Пределы проверки

Программное увеличение меняет геометрию элементов и не является физическими 144/192 DPI; шрифты и нативная отрисовка при реальном переключении монитора могут отличаться. Физические 150/200% для новой формы в этой сессии не выполнялись. Это явно разрешённое в плане моделирование, а не подтверждение аппаратного DPI.

Аппаратное освещение, переподключение и сон повторно не проверялись: протокол и путь записи не изменены. Прежнее согласованное исключение по сну относится к архивному change тихих часов и не переобъявляется успешным аппаратным сценарием здесь. До установки полезен пользовательский просмотр нового окна; коммит, установка, публикация и архивирование не выполнены.
