## 2. Проверка обновлений

- [x] 2.1 `src/UpdateCheck.cs`: запрос к `releases/latest` (15 с, `User-Agent: KbLight/<версия>`), разбор `tag_name`/`html_url`, сравнение по числам, проверка префикса адреса; тексты в `Text.cs` по таблице спеки `interface-language` — проверка: сборка без предупреждений
- [x] 2.2 `CheckUpdates` в `LightSettings` (по умолчанию `true`); трей: таймер 60 с → 24 ч, задача пула, итог через `SynchronizationContext`; уведомление значка и строка журнала один раз на версию; ошибка — одна строка до удачи — проверка: сборка `-p:Version=1.0.0` в отдельную папку, трей из неё через минуту показывает уведомление «Доступна версия KbLight 1.1.0», в журнале `доступна версия 1.1.0: https://github.com/lostintired/sbarda-kblight/releases/tag/v1.1.0`; щелчок по уведомлению открывает страницу релиза
- [x] 2.3 Окно: строка «KbLight <версия>», ссылка «доступна версия <N>», флажок «Проверять обновления» с событием `UpdatesToggled` (сохранение без записи в клавиатуру; при первом запуске — только в памяти) — проверка: в той же тестовой сборке окно показывает «KbLight 1.0.0 · доступна версия 1.1.0», ссылка открывает страницу релиза; снятие флажка — `"CheckUpdates": false` в `settings.json`, в журнале нет строки записи в клавиатуру
