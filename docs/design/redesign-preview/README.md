# Макет нового интерфейса KbLight

Открыть `index.html` в браузере. Это автономный интерактивный макет для согласования оформления, а не новая версия программы. Он не обращается к клавиатуре, настройкам пользователя или сети. Все значения демонстрационные и сбрасываются при обновлении страницы.

Согласованное направление: полный редизайн, только тёмная тема, сдержанный игровой характер, графитовые поверхности. Две широкие колонки для клавиш и Light box, справа более узкая колонка программы. Ориентир размера окна — 1000 × 600 при 100%. Изображения отдельных моделей клавиатур не используются.

Палитра согласована с баннером `docs/images/banner.jpg`: фон `#141316`, панели `#201D24` / `#1A181E`, поля `#17151B`, границы `#3F3847`, текст `#F3F1F5`, вторичный текст `#B5ADBC`. Акценты `#FA2D4C` → `#BF2FDF` взяты с малиново-фиолетовой полосы баннера, ссылки осветлены до `#D8A3F0` для читаемости. Цвета профиля подсветки отделены от брендинга. Шрифт — системный Segoe UI Variable / Segoe UI с кириллицей, без загрузок и зависимостей.

В макете работают выключатели, выбор эффектов, яркость, скорость, разноцветный режим, выбор цвета мышью, полоса оттенка, образцы и точный HEX. RGB показан числами. Доступность параметров зависит от эффекта. Выключение зоны не блокирует редактирование профиля. Переключатель расписания открывает поля времени; сам макет расписание не исполняет. Ссылки и закрытие показывают пояснения вместо действий реальной программы. Название модели, подключение, версия и исходная строка состояния — примеры, не показания устройства.

Что исправляется относительно текущего окна: длинная вертикальная таблица заменяется горизонтальной компоновкой; выключатели попадают в заголовки зон; значения стоят рядом с ползунками; цвет выбирается без отдельного диалога; служебные функции отделены; состояние и закрытие закреплены снизу. Значок приложения — клавиша с буквой K; значки разделов — силуэт WASD без букв (одна клавиша над тремя) и светящаяся полоса с лучами. Это предварительные векторные значки для согласования, включая будущий значок трея. Эти мотивы перенесены в WinForms и ICO в change `redesign-gaming-interface`; рабочая установленная программа отдельно пока не обновлялась.

Макет предназначен для настольного окна. При узкой ширине браузера появляется горизонтальная прокрутка. При реализации WinForms отдельно потребуется проверить масштаб 100/150/200%, прокрутку ограниченной рабочей области, клавиатурную навигацию, английские подписи, отключённое/неподдерживаемое устройство, ошибки записи и активные тихие часы.

Реализация согласованного макета находится в OpenSpec change `redesign-gaming-interface`. Дельта-спецификации отражают редактирование выключенной зоны и постоянную тёмную тему. Ориентир реального внешнего размера — около 1000 × 650; фактическое окно при DPI 96 получилось 1016 × 671 с системной рамкой. Стек WinForms сохраняется, перенос на веб-технологии не планируется.
