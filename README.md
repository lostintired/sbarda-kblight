# KbLight — подсветка клавиатуры sbarda

Замена `sbarda.exe` только для подсветки. Сидит в трее и записывает выбранный эффект в клавиатуру:
при входе в Windows, при подключении клавиатуры, после сна и при каждом изменении в окне настроек.

## Где что лежит

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\KbLight\KbLight.exe` |
| Настройки и журнал | `%LOCALAPPDATA%\KbLight\settings.json`, `kblight.log` |
| Автозапуск | задача планировщика `KbLight` (при входе, `--tray`) |
| Ярлык | «Пуск» → «Подсветка клавиатуры» |

## Ключи запуска

- без ключей — трей и окно настроек (если программа уже запущена, она просто покажет окно);
- `--tray` — только трей, так её запускает автозапуск;
- `--apply` — записать подсветку из настроек и выйти;
- `--check` — записать, только если в клавиатуре стоит другое, и выйти;
- `--autostart on|off` — включить или выключить автозапуск.

## Вместе с sbarda

Запускать `sbarda.exe` не нужно. Если она понадобится для других настроек клавиатуры, подсветку в ней
не меняйте: при следующем входе в Windows KbLight вернёт свою. Автозапуск в sbarda не включайте —
она пишет в автозагрузку несуществующий `G68 Ultra.exe`.

## Сборка и установка

```
dotnet publish src -c Release -o publish
```

Закрыть программу («Выход» в меню значка), скопировать `publish\KbLight.exe` в
`%LOCALAPPDATA%\Programs\KbLight\` и запустить его. Нужен .NET Desktop Runtime 10 (x64).
Значок пересобирается скриптом `python tools/make_icon.py` (нужен Pillow).

## Удаление

1. «Выход» в меню значка в трее.
2. `KbLight.exe --autostart off`.
3. Удалить `%LOCALAPPDATA%\Programs\KbLight`, `%LOCALAPPDATA%\KbLight` и ярлык из «Пуска».

## Документация и доработки

- `openspec/specs/` — что программа обязана делать, по файлу на каждую возможность;
- `docs/ARCHITECTURE.md` — как она устроена, `docs/PROTOCOL.md` — протокол клавиатуры,
  `docs/ADR.md` — принятые решения, `docs/CHANGELOG.md` — версии;
- `CLAUDE.md` и `AGENTS.md` — правила для агентов.

Доработки — через [OpenSpec](https://github.com/Fission-AI/OpenSpec): открыть Claude Code в папке проекта
и начать с `/opsx:propose <что поменять>`, затем `/opsx:apply` и `/opsx:archive`
(в Codex — `$openspec-propose` и далее).
