## ADDED Requirements

### Requirement: Тексты горизонтального интерфейса
Новые видимые подписи и доступные имена SHALL находиться в общем наборе переводов и выбираться по существующему правилу языка. Прежние подписи, ошибки, тексты журнала и расписания SHALL сохранять свои переводы. Подписи времени «Выключить в» и «Включить в» SHALL заменить в новом окне прежние «С» и «До»; доступные имена ручных выключателей SHALL оставаться прежними.

| Русский | English |
|---|---|
| Управление подсветкой | Lighting control |
| Клавиши | Keys |
| Программа | Application |
| Настройки | Settings |
| Устройство | Device |
| Вкл. | On |
| Выкл. | Off |
| Выключить в | Turn off at |
| Включить в | Turn on at |
| Медленно | Slow |
| Быстро | Fast |
| Оттенок | Hue |
| Насыщенность | Saturation |
| Яркость цвета | Color value |
| Цвет <HEX> | Color <HEX> |
| Введите 6 цифр HEX, например #FF8000 | Enter 6 HEX digits, for example #FF8000 |

Обозначения KbLight, Light box, HEX и RGB SHALL быть одинаковыми на обоих языках. Для одинаковых элементов в двух зонах доступное имя SHALL включать название зоны, чтобы их можно было различить.

#### Scenario: Русское окно
- **WHEN** выбран русский язык
- **THEN** видны «Клавиши», «Программа», «Выключить в», «Включить в» и русская ошибка ввода HEX

#### Scenario: Английское окно
- **WHEN** выбран английский язык
- **THEN** видны «Keys», «Application», «Turn off at», «Turn on at» и английская ошибка ввода HEX; заголовок Light box не меняется
