# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/): мажор — ломающее изменение (например, `settings.json`, который старая версия не прочтёт), минор — новая функция, патч — только исправления. Номер версии — `<Version>` в `src/KbLight.csproj`.

## [1.3.0] — 2026-10-06

### Добавлено

- RGB neon light box ZH99 HE — вторая подсветка, которую sbarda не настраивает, а клавиатура сбрасывает при отключении питания. В окне группа «Light box»: режим («Плывущие линии», «Мигание», «Ровный цвет», «Дыхание», «Выключен»), яркость, скорость, цвет и «Разноцветный»; KbLight пишет его вместе с основной подсветкой во всех тех же случаях. Настройки — поле `LightBox` в `settings.json`. Найдено опытом на клавиатуре: байты 24–31 блока настроек (`docs/PROTOCOL.md`, §4).
- Переход с 1.2.0 не меняет light box: трей берёт его из клавиатуры при первом чтении и сохраняет.
- Поле `lightBox` в файле модели; у встроенной ZH99 HE включено. Без него байты 24–31 не трогаются, как раньше.
- Состояние в журнале у моделей с light box — с частью ` | box mode=… brightness=… speed=… multicolor=… rgb=…`.
- `tools/kbtool.py setbytes <смещение>=<hex> …` — запись произвольных байт блока с перечитыванием, для опытов.

### Документация

- README на китайском (`README.zh-CN.md`), испанском (`README.es.md`) и бразильском португальском (`README.pt-BR.md`); интерфейс программы по-прежнему английский и русский.
- Новые скриншоты окна с группой «Light box».

## [1.2.0] — 2026-10-04

### Добавлено

- Релизы собирает GitHub Actions по тегу `vX.Y.Z` (`.github/workflows/release.yml`): exe, SHA256 и описание; на каждый push — проверка сборки и спецификаций (`build.yml`).
- Версия видна: строка «KbLight <версия>» в окне, `KbLight <версия>` в журнале при запуске трея, ключ `--version`.
- Проверка обновлений: трей через минуту после запуска и раз в сутки спрашивает GitHub о последнем релизе; о новой версии говорят ссылка в окне, уведомление значка и строка журнала, ссылка открывает страницу релиза. Ничего не скачивается само. Флажок «Проверять обновления» в окне, поле `CheckUpdates` в `settings.json` (по умолчанию включено; версия 1.1.0 поле пропускает).

## [1.1.0] — 2026-10-04

### Изменено

- Первый запуск, без `settings.json`, больше не записывает в клавиатуру настройки автора («Рябь от нажатий»): трей читает подсветку, которая уже стоит в клавиатуре, и сохраняет её в `settings.json`.

### Добавлено

- Код возврата 3 у `--apply` и `--check`: `settings.json` ещё нет, клавиатура не тронута.
- Файлы моделей клавиатур: встроенная ZORNER ZH99 HE (`src/models/`) и свои в `%LOCALAPPDATA%\KbLight\models\`, без перезапуска. Клавиатура `19F5` без файла модели не получает ни одной команды: статус `Unsupported`, строка состояния «Клавиатура 19F5:<PID> не знакома программе…», код возврата 4.
- Окно: строка «Клавиатура: <модель>», список эффектов из файла модели, ссылка «Модели» — открывает папку моделей.
- Поле `Model` в `settings.json` — `VID:PID` последней клавиатуры; прежняя версия его пропускает.
- Английский интерфейс: окно, меню, строка состояния, названия эффектов (как в английской sbarda) и журнал — по-английски, если Windows не на русском; переменная `KBLIGHT_LANG=ru|en` выбирает язык вручную. На русской Windows тексты прежние. Статусы и состояние `effect=…` в журнале одинаковы на обоих языках.
- `tools/make_model.py` — файл модели из подключённой клавиатуры и базы sbarda; `tools/kbtool.py --pid XXXX`; `docs/ADDING-A-KEYBOARD.md` — как добавить свою модель.

### Документация

- `README.md` по-английски для всех владельцев клавиатур sbarda (симптомы, установка, SmartScreen, сломанный автозапуск sbarda, оговорка), русский — `README.ru.md`; лицензия MIT — `LICENSE`.
- Проект переведён на OpenSpec: базовые спецификации поведения в `openspec/specs/` (8 capability), `openspec/config.yaml`, `docs/ARCHITECTURE.md`, `docs/PROTOCOL.md`, `docs/ADR.md`, `CLAUDE.md`, `AGENTS.md`. Поведение программы не менялось.
- Инструменты исследования протокола перенесены в проект: `tools/kbtool.py`, `tools/capture/`.

## [1.0.0] — 2026-10-04

### Добавлено

- Значок в трее; запись подсветки при входе в Windows, при подключении клавиатуры, после сна, после правки в окне и по команде «Применить сейчас».
- Окно «Подсветка клавиатуры»: 20 эффектов, яркость, скорость, цвет, разноцветный режим, направление, автозапуск, состояние, журнал.
- Автозапуск — задача планировщика `KbLight`; ключи `--tray`, `--apply`, `--check`, `--autostart on|off`.
- Журнал `%LOCALAPPDATA%\KbLight\kblight.log`.
